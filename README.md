# Book Reader

A calm, responsive personal reading app with a library, immersive reading view, chapter navigation, bookmarks, search, typography controls, page tones, and local preference persistence.

## Run locally

On Windows, double-click `start-server.bat`.

Or run:

```bash
npm start
```

Open [http://100.127.36.5:3511](http://100.127.36.5:3511) from a connected remote device, or [http://localhost:3511](http://localhost:3511) on this computer.

No package installation is required; the server uses Node.js built-in modules.
