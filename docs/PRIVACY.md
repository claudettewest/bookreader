# Privacy statement

Offline Bookshelf is private and offline-first. It requests no Internet permission and contains no account system, advertising, analytics, telemetry, tracking, cloud sync, remote configuration, or external API integration.

Imported books, private working copies, extracted resources, covers, metadata, reading positions, listening positions, bookmarks, notes, search data, and preferences remain on the Android device. The app never uploads book content or reading activity.

The user selects source files and backup destinations through Android's Storage Access Framework. An original source file is never deleted unless a future explicit delete action is confirmed by the user and Android grants that action.
